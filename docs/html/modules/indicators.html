class DonchainChannelsIndicatorHandler(window_size: int = 20)¶

Bases: IndicatorHandlerBase

Implements donchain channels indicator. It indicates the highest and the lowest price for the certain period, creating so called channel. It also calculates average price as the average of the lowest and the highest price.
